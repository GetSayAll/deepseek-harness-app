2026 年 8 月 14 日

DS Harness 0.1.2

预览版

补齐系统通知与应用内更新，并优化首次打开时的工作区窗口尺寸、对话控制和 Composer 交互。

  • 新增系统通知：任务完成、需要审批或回答问题时提醒，点击通知可返回对应会话。
  • Dock 图标显示待处理交互数量，通知仅展示通用状态，不包含会话内容。
  • 新增应用内更新，支持每日自动检查和手动检查，预览版通道默认关闭。
  • 设置和关于页面增加检查更新与版本历史入口，更新窗口会显示版本说明。
  • 调整首次创建主窗口的默认尺寸，更适合大屏工作区布局。
  • 对话页支持在对话与运行轨迹之间切换，工具轨迹仅显示工具卡并可打开详情。
  • 空白会话可选择助手预设，已开始的会话会锁定预设；消息布局和 Composer 拖拽高度得到优化。

2026 年 8 月 14 日

DS Harness 0.1.1

正式版

首个原生 macOS 版本，采用 SwiftUI“深海工作台”三栏界面，并只在桌面生命周期与系统能力处使用 AppKit。

  • 内置 Node 运行时与 Harness Host，不需要 localhost 或额外运行环境。
  • 提供原生工作区、会话、流式对话与 Markdown 阅读体验。
  • 显示工具调用与运行详情，并支持审批和结构化问答。
  • DeepSeek API Key 通过只写凭据接口保存，界面不会读取或回显密钥。
  • 支持 Host 断线恢复、原生设置、关于窗口与常用快捷键。
