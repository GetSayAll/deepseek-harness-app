DS Harness 0.1.1

正式版

首个原生 macOS 版本，采用 SwiftUI“深海工作台”三栏界面，并只在桌面生命周期与系统能力处使用 AppKit。

  • 内置 Node 运行时与 Harness Host，不需要 localhost 或额外运行环境。
  • 提供原生工作区、会话、流式对话与 Markdown 阅读体验。
  • 显示工具调用与运行详情，并支持审批和结构化问答。
  • DeepSeek API Key 通过只写凭据接口保存，界面不会读取或回显密钥。
  • 支持 Host 断线恢复、原生设置、关于窗口与常用快捷键。
